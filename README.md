# 华人婚绿网 V1 首页

这是根据首页设计稿制作的可直接部署静态版本。

## 文件

- `index.html`：页面结构与 SEO 信息
- `styles.css`：桌面端和移动端响应式样式
- `app.js`：导航、弹窗、交友筛选、喜欢按钮、免费评估演示
- `netlify.toml`：Netlify 部署、跳转与安全响应头

## 部署

本仓库已按 Netlify 根目录部署配置：

- Base directory：`.`
- Build command：留空
- Publish directory：`.`

连接 GitHub 后，提交到 `main` 分支会自动触发生产部署。
